# THINK 유니버스 통합 철학 기반 — BoozaThink 펜 스케치 홍보 시나리오 & 4슬롯 자동화 플레이북

## 1. 핵심 브랜드 철학 (“Think = 막연한 생각이 펜으로 그려지며 선명해지는 과정”)
- `BoozaThink` · `SAThink` · `KoreaThink` 세 서비스의 공통 단어 **`Think`**는 **머릿속에서 안개처럼 막연하고 복잡해 보이던 생각이, 하얀 종이 위에 펜으로 한 획씩 스케치되며 마침내 한 장의 선명한 그림과 명쾌한 해답으로 완성되는 과정**을 상징합니다.
- 특히 **BoozaThink**의 모든 홍보 콘텐츠는 겁을 주는 방식이 아니라, **펜이 사각사각 가게와 단계별 징검다리를 그려 나가는 동안 “아, 순서만 알면 창업이 이렇게 쉽고 할 만하구나!”라는 이야기가 완성되는 따뜻한 스케치 스토리텔링**으로 통일합니다.

---

## 2. 계정 완전 분리 원칙 & 무손실 아이디 스왑(Handle Swap) 수칙
- **절대 분리 원칙**: `KoreaThink`(다국어 글로벌 여행), `SAThink`(한국 가계 재테크·부동산), `BoozaThink`(한국 창업·자영업·셀러)는 계정·API 토큰·`.env`·스케줄러 상태를 100% 물리적으로 분리합니다.
- **무손실 아이디 스왑 권장 절차**:
  1. `GOREA` Windows 작업 스케줄러(`KoreaThink_Daily_Social_Drip_*`) 일시 중지
  2. 기존 영어·일본어 여행 트윗과 팔로워가 쌓인 X 계정의 `@아이디`만 `@boozathink` → `@koreathinkcom`(또는 `@koreathink_official`)으로 변경하여 기존 게시물·팔로워·알고리즘·API 토큰 100% 보존
  3. 다른 크롬 프로필에 미리 열어둔 신규 한국어 전용 계정에서 방금 풀린 `@boozathink` 아이디를 10초 내 즉시 선점 (스나이핑 봇 방지 + 100% 순수 한국어 알고리즘 출발)
  4. 스레드·인스타그램·유튜브(별도 GCP 프로젝트로 일일 10,000 유닛 업로드 쿼터 분리)도 각각 브랜드별 독립 계정 및 크롬 프로필로 격리

## 3. 하루 4슬롯 자동 발송 시간표 (`SAThink` · `KoreaThink`와 시간 충돌 ZERO)
- **슬롯 1 (`08:20 KST` · 출근길)**: 직장인 예비창업자·온라인 셀러 타깃 → X + IndexNow (`1분 소자본·셀러 창업 스케치 노트`)
- **슬롯 2 (`12:15 KST` · 점심시간)**: 점심 식사 후 투잡·무인창업·내 가게를 꿈꾸는 직장인 타깃 (`SAThink 12:30`과 15분 간격 분리) → 스레드(1회차) + X + 네이버 (`점심시간 3분 창업 도감 스케치 카드`)
- **슬롯 3 (`15:15 KST` · 오후 브레이크타임)**: 식당·카페·매장 현직 사장님 타깃 → X + 자영업 커뮤니티 시딩 카드 (`포장 전환·스마트상점 국비 보조·저금리 대환 스케치`)
- **슬롯 4 (`22:30 KST` · 마감 후 심야 본편)**: 하루 마감 후 내 사업을 진지하게 그려보는 골든타임 → 유튜브 쇼츠 + 인스타 릴스 + 스레드(2회차) (`펜이 사각사각 그리며 완성하는 ‘참 쉬운 창업’ 9:16 스케치 스토리 영상`)

## 4. 자동화 엔진 구성 (`Boozathink/marketing_engine/`)
- `build_boozathink_sketch_cards.py`: 모눈·크로키북 질감 위에 연필 밑그림 → 펜 드로잉 → 파스텔·형광펜 착색으로 완성되는 `1080×1350` 스케치 카드 생성 (`backend/public/promo-cards/` 퍼스트파티 서빙)
- `build_boozathink_sketch_shorts.py`: 만년필 드로잉 궤적 애니메이션(`compute_kinetic_trace_path`) + 사각사각 펜 폴리 사운드 + 손그림 호흡 모션(`Line-Boil`)으로 이야기가 완성되는 `1080×1920` 쇼츠 MP4 생성 및 `BoozaThink_유튜브_릴스_직접업로드_대기함` 연동
- `boozathink_meta_guard.py`: 퍼스트파티 URL 검증 및 Meta 호출 간격 방어막
- `boozathink_4slot_scheduler.py` + `register_boozathink_tasks.ps1`: `08:20 / 12:15 / 15:15 / 22:30` 4슬롯 무창 자동 실행 및 KST 일자별 중복 발송 차단
